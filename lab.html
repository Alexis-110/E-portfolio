Documentation Technique : Lab Enterprise

Déploiement complet d'une infrastructure d'entreprise virtualisée : Pare-feu pfSense, Domaine AD DS Windows Server 2025, Supervision Zabbix 7.0 LTS et Ticketing/Inventaire GLPI 10 sous Debian 13.

pfSense Windows Server 2025 Debian 13 Active Directory GLPI 10 Zabbix 7.0 LTS LDAP Agent GLPI

🖧
1. Architecture & Plan d'Adressage IP

L'infrastructure est entièrement isolée et orchestrée sous VirtualBox. Elle simule un réseau d'entreprise partitionné et sécurisé.

pfSense En fonction

  • Rôle : Routeur / Pare-feu
  • WAN : DHCP (Accès Internet)
  • LAN IP : 192.168.1.1 /24

Windows Server 2025 Opérationnel

  • Rôle : AD DS, DNS, DHCP
  • Domaine : entreprise.local
  • IP Fixe : 192.168.1.10 /24

Debian 13 (GLPI / Zabbix) En fonction

  • Rôle : Helpdesk & Supervision
  • Services : Apache2, MariaDB
  • IP Fixe : 192.168.1.101 /24

Windows 11 CLT Client

  • Rôle : Poste de travail utilisateur
  • Domaine : Joins à entreprise.local
  • IP : DHCP (AD)

🛡️
2. Configuration du Pare-feu pfSense

  • Attribution des interfaces réseau :

    Mise en place de l'interface WAN (Accès au réseau physique) et de l'interface LAN configurée sur le réseau interne 192.168.1.0/24.

  • Règles de filtrage & Flux réseau :

    Autorisation des flux DNS, HTTP/HTTPS vers le serveur Debian (`192.168.1.101`) et routage des requêtes Active Directory (Port 389 LDAP / 88 Kerberos).

🏰
3. Active Directory DS, GPO & Jonction Domaine

  • Promotion du Domaine :

    Installation du rôle AD DS sur Windows Server 2025 et création de la forêt entreprise.local. Structuration des Unités d'Organisation (ex: UO Informatique) et ajout des utilisateurs (Jordan Guillet, etc.).

  • Résolution de la signature LDAP obligatoire (Erreur 8) par GPO :
    Windows Server 2025 impose par défaut la signature obligatoire des paquets LDAP, ce qui bloque la synchronisation GLPI standard.
    📖 Guide pas-à-pas : Modifier la GPO du serveur pour autoriser GLPI (Erreur 8)
    1. Sur le serveur Windows Server 2025, ouvre la Gestion des stratégies de groupe (gpmc.msc).
    2. Déroule l'arbre : Domaine > entreprise.local > Default Domain Policy.
    3. Fais un clic droit sur Default Domain Policy et sélectionne Modifier.
    4. Navigue vers l'emplacement suivant :
      Configuration ordinateur > Stratégies > Paramètres Windows > Paramètres de sécurité > Stratégies locales > Options de sécurité
    5. Cherche la stratégie : Sécurité réseau : exigences de signature d'un serveur LDAP.
    6. Fais un double-clic dessus, coche Définir ce paramètre de stratégie et règle la valeur sur N'exige pas la signature.
    7. Valide par Appliquer puis OK.
    8. Ouvre un invite de commandes (CMD en Admin) et force l'actualisation des stratégies :
      gpupdate /force
  • Jonction du poste client Windows 11 Pro au domaine AD :

    Intégration du poste de travail pour appliquer les stratégies d'entreprise et tester les sessions utilisateurs.

    📖 Guide pas-à-pas : Joindre un PC Windows 11 Pro au domaine AD
    1. Configurer le DNS : Sur le PC Windows 11, va dans les paramètres de la carte réseau et définis le DNS primaire avec l'IP du serveur AD (192.168.1.10).
    2. Vérifie la connectivité en ouvrant CMD et en tapant : ping entreprise.local.
    3. Ouvre les Paramètres Windows > Système > En savoir plus (ou recherche Système avancé).
    4. Clique sur Domaine ou groupe de travail (ou Renommer ce PC (avancé)).
    5. Dans la fenêtre Propriétés système, clique sur le bouton Modifier....
    6. Dans la section Membre de, coche Domaine et saisis entreprise.local. Clique sur OK.
    7. Une fenêtre s'ouvre : indique les identifiants de l'administrateur du domaine (ex: Administrator et son mot de passe).
    8. Un message indique "Bienvenue dans le domaine entreprise.local". Redémarre le PC Windows 11.

4. Déploiement GLPI 10 & Interconnexion LDAP

  • Installation LAMP & GLPI sous Debian 13 :

    Déploiement d'Apache2, MariaDB, PHP 8.3 et des extensions requises (php-ldap, php-mysqli).

  • Configuration du Connecteur LDAP & Mapping des attributs :
    📖 Guide pas-à-pas : Connecter GLPI à l'Active Directory
    1. Dans l'interface GLPI, va dans Configuration > Annuaires LDAP.
    2. Clique sur le bouton + (Ajouter) et remplis les champs :
      • Nom : Active Directory Entreprise
      • Serveur par défaut : Oui
      • Hôte : 192.168.1.10 | Port : 389
      • BaseDN : CN=Users,DC=entreprise,DC=local
      • DN du compte : CN=Administrator,CN=Users,DC=entreprise,DC=local
      • Mot de passe du compte : Mot de passe administrateur AD
      • Champ de l'identifiant : sAMAccountName
    3. Clique sur Enregistrer, puis clique sur Test de liaison à l'annuaire LDAP. Le message "Test réussi" doit s'afficher.
    4. Va dans l'onglet Test / Importation pour vérifier les filtres :
      Filtre de recherche : (objectClass=user)
    5. Dans l'onglet Champ appartenance à un groupe, configure le mapping des utilisateurs :
      • Nom de famille : sn
      • Prénom : givenname
      • E-mail : mail
    6. Pour importer les comptes : va dans Administration > Utilisateurs > Liaison annuaire LDAP > Importation de nouveaux utilisateurs.
  • Automatisation CLI (Cron) :

    Planification du script sous Debian 13 pour resynchroniser les utilisateurs en arrière-plan :

    */15 * * * * php /var/www/html/glpi/front/cron.php --force ldap

📦
5. Déploiement de l'Agent GLPI (Inventaire Matériel)

Remontée automatique de la configuration matérielle et logicielle des postes vers le serveur GLPI.

📖 Guide pas-à-pas : Installer et forcer l'inventaire de l'Agent GLPI
  1. Télécharge le programme d'installation GLPI-Agent-x64.msi sur le poste Windows client ou le serveur Windows 2025.
  2. Lance l'installation et choisis le mode d'installation complet.
  3. Lors de l'étape Cible d'inventaire (Target), sélectionne Server et saisis l'URL de ton serveur GLPI :
    http://192.168.1.101/glpi/front/inventory.php
  4. Poursuis l'installation jusqu'à la fin.
  5. Forcer l'inventaire immédiat : Ouvre ton navigateur web sur la machine cliente et accède à l'interface locale de l'agent :
    http://localhost:62354/
  6. Clique sur le bouton Force Inventory.
  7. Retourne sur GLPI dans Parc > Ordinateurs : la machine apparaît avec tous ses composants (CPU, RAM, Disques, OS).
